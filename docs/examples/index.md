## Local Development

Clone the repository and run the examples locally:

```bash
# Clone the repository
git clone https://github.com/saqqdy/directix.git
cd directix

# Install dependencies
pnpm install

# Run Vue 3 examples
pnpm example:dev

# Or run Vue 2 examples
cd examples/vue2
pnpm install
pnpm dev
```
