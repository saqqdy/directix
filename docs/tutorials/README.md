## 制作规范

### 视频规格

- 分辨率：1920x1080 (1080p)
- 帧率：30fps
- 编码：H.264
- 音频：AAC, 128kbps

### 录制要求

- 清晰的代码演示，字号不小于 18px
- 平滑的操作演示，避免跳跃剪辑
- 清晰的语音讲解，无背景噪音
- 适当的背景音乐（可选）

### 开场与结尾

每个视频包含：
- 统一的开场动画（3秒）
- 视频标题和章节目录
- 结尾总结和下集预告
- 统一的片尾动画（5秒）
