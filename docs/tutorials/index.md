## Production Standards

### Video Specs

- Resolution: 1920x1080 (1080p)
- Frame rate: 30fps
- Encoding: H.264
- Audio: AAC, 128kbps

### Recording Requirements

- Clear code demos, font size ≥ 18px
- Smooth operations, avoid jump cuts
- Clear narration, no background noise
- Optional background music
