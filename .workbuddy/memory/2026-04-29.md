## 修复 useResize 示例错误

**问题**：`examples/vue2` 和 `examples/vue3` 的 `composables.vue` 中，`useResize` 示例代码使用了错误的 API。

**根本原因**：
- 传了不存在的 `handler` 参数，应为 `onResize`
- 手动创建了 `resizeWidth = ref(0)` 和 `resizeHeight = ref(0)`，而 `useResize` 返回值中已内置 `width`/`height` 响应式 ref

**正确 API**：
- 返回 `{ width, height, bind, stop }`，`width`/`height` 是 `Readonly<Ref<number>>`，bind 时自动初始化为元素当前尺寸
- options 回调用 `onResize`，参数为 `ResizeInfo { width, height, contentRect }`
- 应在 `setup()` 顶层调用，将返回的 `width`/`height` 重命名用于模板

**修复文件**：
- `examples/vue3/src/demos/composables.vue`
- `examples/vue2/src/demos/composables.vue`

## 修复 useLongPress 示例错误

**问题**：`examples/vue2` 和 `examples/vue3` 的 `composables.vue` 中，`useLongPress` 示例代码使用了错误的 API。

**根本原因**：
- 传了不存在的 `handler` 参数，应为 `onTrigger`
- 自定义了 `isLongPressing = ref(false)`，不会联动，应使用 `useLongPress` 返回的 `isPressing`

**正确 API**：
- 返回 `{ isPressing, start, stop, bind }`
- options 回调用 `onTrigger`（长按触发）、`onStart`（按下）、`onCancel`（取消）、`onTick`
- 应在 `setup()` 顶层调用 `useLongPress()`，将 `isPressing` 重命名导出为模板用的 `isLongPressing`

**修复文件**：
- `examples/vue3/src/demos/composables.vue`
- `examples/vue2/src/demos/composables.vue`

## 修复 useHover 示例错误

**问题**：`examples/vue2` 和 `examples/vue3` 的 `composables.vue` 中，`useHover` 示例代码使用了错误的 API。

**根本原因**：
- 示例代码误将 `useHover` 当作其他 composable（如 `useClickOutside`）来用，传了不存在的 `handler` 参数
- 自定义了一个 `isHovering = ref(false)` 变量，而实际上 `isHovering` 应由 `useHover()` 返回

**正确 API**：
- `useHover(options)` 的 options 只接受 `onEnter`、`onLeave`、`class`、`enterDelay`、`leaveDelay`，**没有 handler**
- 返回 `{ isHovering: Readonly<Ref<boolean>>, bind: (el) => () => void }`
- 应在 `setup()` 顶层直接调用 `useHover()`，`onMounted` 中只调用 `bind(el)`

**修复文件**：
- `examples/vue3/src/demos/composables.vue`
- `examples/vue2/src/demos/composables.vue`
