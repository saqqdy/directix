# 2026-05-01

## enterprise.vue — 全面重写优化

优化了 `examples/vue3/src/demos/enterprise.vue` 和 `examples/vue2/src/demos/enterprise.vue`：

### API 修复
- `AuditLogStats` 接口：原来用 `totalLogs`/`errorCount`/`warnCount`/`infoCount`，实际 API 返回 `totalEntries`/`byLevel.error`/`byLevel.warn`/`byLevel.info`
- `hasPermission` 是 async（`Promise<boolean>`），改用 `hasPermissionSync`
- `configureEnterprisePermission` 需要完整的 `sources` 配置（`type: 'static'` + `permissions`），且需调用 `manager.initialize()` 才能工作
- `acknowledgeAlert` 需要两个参数 `(alertId, acknowledgedBy)`，原来只传了一个
- `addHealthCheck` 需要 `HealthCheck` 对象 `{ name, check, interval, timeout, enabled }`，不是 `(name, fn)`
- `getConfigSnapshots()` 不接受 `{ limit }` 参数
- `rollbackConfig` 参数是 `version`，不是 `snapshotId`

### UI 全面升级
- 渐变色 section header（绿→深蓝）
- 统计卡片带 hover 边框效果
- 日志面板：左侧彩色边条 + level badge
- 监控指标：图标+数值组合卡片，health 状态彩色边框
- 配置中心：双栏布局（表单+快照历史）
- 权限管理：三栏布局（角色卡片+检查区+审计轨迹），Quick Check 按钮
- 所有按钮带 emoji 图标和 hover 动效
- 响应式布局支持
